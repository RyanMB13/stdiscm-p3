==============================================================================
P3 - NETWORKED PRODUCER AND CONSUMER (Go implementation)
==============================================================================

SYSTEM REQUIREMENTS
-------------------
1. Producer Machine: macOS (Apple Silicon/M-Series assumed) with Go installed.
2. Consumer Machine: Ubuntu Virtual Machine (ARM64) with FFmpeg installed.
3. Network: Both machines must be on the same network (Bridged Adapter recommended).

==============================================================================
PART 1: PREPARATION (One-time setup)
==============================================================================

A. ON UBUNTU VM (The Server)
   1. Install FFmpeg (Required for video compression bonus):
      $ sudo apt update
      $ sudo apt install ffmpeg

   2. Find your IP Address:
      $ ip addr
      (Note the IP address, e.g., 192.168.64.8. You will need this later.)

B. ON MAC (The Client)
   1. Create test folders for the producer threads:
      (Run this in the project root)
      $ mkdir folder1
      $ for i in {2..5}; do cp -r folder1 folder$i; done
      
   2. Place at least one sample .mp4 video inside 'folder1'.

==============================================================================
PART 2: DEPLOYMENT
==============================================================================

1. BUILD FOR LINUX (Run on Mac)
   Since the Mac is Apple Silicon and the VM is ARM64, use arm64 architecture:
   
   $ GOOS=linux GOARCH=arm64 go build -o consumer-linux consumer/main.go

2. TRANSFER FILES TO VM (Run on Mac)
   Replace <IP> with your VM's IP address (e.g., 192.168.64.8).
   
   $ ssh ryan@<IP> "mkdir -p ~/video_project"
   $ scp -r consumer-linux consumer/templates ryan@<IP>:~/video_project/

==============================================================================
PART 3: RUNNING THE SYSTEM
==============================================================================

STEP 1: START THE CONSUMER (Server)
   1. SSH into your VM:
      $ ssh ryan@<IP>
      
   2. Navigate to the folder:
      $ cd ~/video_project
      
   3. Make the binary executable:
      $ chmod +x consumer-linux
      
   4. Run the Consumer (Example: 2 threads, Queue size 5):
      $ ./consumer-linux -c 2 -q 5

   (You should see: "Consumer running. GUI at http://localhost:8080")

STEP 2: START THE PRODUCER (Client)
   1. Open a NEW terminal on your Mac.
   2. Navigate to the project root.
   3. Run the Producer pointing to the VM's IP:
   
      $ go run producer/main.go -p 2 -addr "<IP>:50051"

STEP 3: VIEW THE GUI
   1. Open Safari or Chrome on your Mac.
   2. Visit: http://<IP>:8080

==============================================================================
TESTING BONUS FEATURES
==============================================================================

1. QUEUE FULL (Backpressure)
   - Stop the Consumer.
   - Run Consumer with low capacity: ./consumer-linux -c 1 -q 1
   - Run Producer with high load:    go run producer/main.go -p 5 ...
   - Observe Producer logs: "Queue Full. Sleeping 5s..."

2. DUPLICATE DETECTION
   - Upload a file.
   - Run the Producer again with the same file.
   - Observe logs: "Upload Failed: Duplicate Content"

3. VIDEO COMPRESSION
   - Check the 'uploads' folder on the VM: $ ls -lh ~/video_project/uploads
   - Compressed files will be smaller than the originals.
